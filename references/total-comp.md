# 总包(Total Comp)计算与 Offer 评估

> 谈薪永远算**年化总包**，不要只看月薪。月数、bonus、股票、签字费差异巨大。

## 年化总包公式

```
年化总包 = 月薪 × 月数 + 年终奖金(target bonus) + 股票/期权年化 + 签字费(摊到年) + 可货币化福利
```

### 各项说明
- **月数**：12 / 13 / 14 / 15.5 … 一定要问清"发几个月"。15 万×12 和 12 万×15 差很多。
- **年终奖金**：问清是 **target（写进合同）** 还是 ** discretionary（看绩效，可能为 0）**。视频里 HR 明确说"target bonus 75k 写在合同上"= 稳的。
- **股票/期权**：上市公司按授予日股价×股数÷归属年限算年化；未上市公司问清估值、归属(vesting)节奏、行权价。
- **签字费(Sign-on)**：通常一次性，按 /4 摊到每年比较公平。
- **可货币化福利**：补充医疗、餐补、住房补贴、通勤、培训预算——能折现的算进去。

## 决策三档

1. **总包 ≥ 真实期望** → 直接接，礼貌确认细节即可，不必反价（反价可能弄巧成拙）。
2. **底线 ≤ 总包 < 真实期望** → 走反价流程（见 scripts.md 阶段④），用"条件承诺"试一把。
3. **总包 < 底线** → 礼貌拒绝（scripts.md 末尾话术），除非这个 offer 是你唯一的 BATNA。

## 涨幅参考锚（市场常见，非绝对）

- 平薪跳槽：除非岗位/成长性远超现职，否则不划算。
- 10%–15%：常规跳槽合理涨幅（视频中 HR 给的"市场合理范围"）。
- 15%–25%：需要工作量/职责明显增加，或带竞品 offer。
- 25%+：通常需要走特殊审批，要有强理由（晋升级、稀缺技能、竞品 offer）。

> 注意：涨幅锚是相对**当前总包**算的，不是月薪。别被"涨 30%"忽悠实际总包没动。

## BATNA 清单（谈判前必填）

- 我手里有几个 offer / 在面的机会？
- 最强的那个走到哪一步了？预期多久出结果？
- 如果这个 offer 吹了，我能接受留下/继续找吗？
- 现职有没有 counter-offer 的可能？（留人 offer 通常 +10%~20%）

BATNA 越强，你越敢反价；BATNA 弱，就别把"我还有别的"当筹码乱用。

# Offer 质量评估 ·「灵魂四问」（到手后必问）

> 提炼自布布糕《谈薪判断offer质量》（7326844157807299890）。
> 总包算完觉得数字满意 ≠ 这是个好 offer。HR 报完薪资、你感觉可接受时，接一句："薪资 OK，但我还有几个问题想问。"——这四问决定你接的是不是一个"天花板 offer"。

| # | 问题 | 在判断什么 | 信号解读 |
|---|------|-----------|---------|
| 1 | **公司 annual increase（普涨）大概多少？能给个区间参考吗？** | 公司整体调薪力度 | 过去三年每年普涨 6%–8% = 正常/中等偏上；HR 支支吾吾、刻意回避 = 大概率没有普涨，进去即冻薪。 |
| 2 | **我这个 title（如 Manager）在公司的薪资区间是多少？** | 自己是否踩在级别上限 | 区间 30–50 万而你就是 50 万 = 已到顶，短期除升职无涨薪手段 → 此时可谈 **title 上调**（钱不变，级别上提）。 |
| 3 | **一年有几次薪酬 review？** | 升职加薪的机会窗口 | 最少 1 次；好公司 1 年 2 次 = 一年两次升职加薪机会。 |
| 4 | **部门架构 / 我的汇报线是谁 / 内部 stakeholder 级别如何？** | 未来话语权与压力来源 | 老板不懂行（如莫名汇报给 HRD/CFO）= 压力大、听劝程度低；stakeholder 级别低 = 岗位内部话语权不重。 |

**为什么有效**：问完四问，你对接下来的工作会有"清晰的画面感"，不踏实感消失；这些问题本身也是专业信号，HR 会重新评估你的成熟度。

## 跨界跳槽（民企→外企）的流水认定清单

> 提炼自布布糕《民企回外企谈薪》（7434392955365887290）。
> 外企 C&B 认 fixed（固定）部分，浮动奖金认定极严。跨界跳槽前先把自己的薪资流水"外企化"：

- [ ] 奖金是否**写进劳动合同 / offer**？还是口头说的一个数？
- [ ] 奖金**是否有官方系数**（如签的 30%）？口头系数无效。
- [ ] 奖金**发放形式是否可追溯**？支付宝/个人账户转账 = 大概率不被外企 C&B 认定。
- [ ] 月薪流水是否完整？fixed = 月薪 × 月数，别把奖金当 fixed 自我高估。

**谈薪时的破局**（猎头视角）：全透明先降预期 → 摸清候选人 bottom line 让他先报高价锚高 → 用聊天记录/背调声明做证据 → 设安全阀（背调核实，结果有出入 HR 有权收回 offer，候选人写声明邮件无怨言）→ 内部博弈争取最终数字。案例：85 万底 → C&B 松口 **105 万 / 月薪 70k / base 涨幅 40%**。

## 看机会前算清所有 cash 和 benefits（《看机会前把所有cash和benefits算进去》）

> **第一性原则：看机会前，必须把所有能算到的 cash 和 benefits 全部算进去。** 对方会告诉你"哪些不能作参考"，但**你遗漏了就麻烦大了**——offer 数字出了才发现漏了 bonus，猎头和 HR 都会极其被动。

### 猎头/HR 问期望薪资时，要确认到 breakdown 级别
- 不要只问"600k 你 OK 吗"就完事——还要追问：**"什么样的数字你肯定是会接的？"**（不是"舒服的数字"，而是"肯定会接的数字"）。
- 漏报 bonus 的后果（情景剧案例）：候选人说 600k 行 → 猎头走完内部流程出 offer → 候选人这时才想起"还有个外部 bonus"，加上后实际 530k，期望 640k → 猎头被骂"不专业"、差点被拉黑。
- **教训**：候选人一开始就没问清楚 breakdown，猎头也没深挖。双方都要在第一通电话就把总包拆解到：月薪×月数 + 年终奖（官方系数）+ sign-on bonus + 股票/期权年化 + 其他 benefits 的现金价值。

### 用"三年后薪资对比"算总账（说服自己/说服候选人）
当 offer 数字没到期望但平台/业务更好时，别只看当下涨幅，算**三年后的复利账**：
- 案例（东门子 reporting 转 Tanac 财务）：东门子 annual increase 约 3%，留 3 年后 508k→579k；Tanac 补偿（annual increase）8%，3 年后约 **755k**——**差近 20 万**。这还是默认跳槽后不升值的保守估计。
- **跳槽不全为钱**：仅为了钱跳通常不建议（跳槽有风险）。要综合 scope/业务线/平台——"这一次是 Tanac（全球四大奢侈品家族之一）给你机会"，平台提升本身就是价值。

### Sign-on bonus 的操作（差额的弥补工具）
当 base 给不到期望、但业务想签人时，用 **sign-on bonus** 弥补差额：
- 案例：base 顶到 600k 给不到 640k → 猎头争取 sign-on bonus 40k → 第一年约 620k（接近期望），第二年补偿稍低但可接受。
- sign-on 的发放节奏可谈：**入职给一半（20k）+ 试用期后给另一半（20k）**，既锁定候选人又留缓冲。
- sign-on 的成本认知管理：要让候选人知道"这 40k 是猎头忙了一天重新走审批争取的"——否则候选人觉得 sign-on 来得容易，下次还会漫天要价。

### 候选人侧启示
1. **第一通电话就把总包 breakdown 算全**：月薪+年终奖+sign-on+股票年化+benefits 现金价值，别漏。
2. **被问期望时，主动报"肯定接的数字"**，别报"舒服的数字"造成误解。
3. **算账看三年**：当下涨幅不够时，用三年后复利账（含 annual increase 差异）对比，别只盯 base 涨幅。
4. **sign-on bonus 是可谈项**：base 到顶了，差额用 sign-on 弥补，且发放节奏可拆（入职一半+试用期后一半）。
