# 离职时机决策框架（模块A）

> 提炼自布布糕《多数人踩不中的完美离职时间》（视频ID 7666720142035113201）。

## 核心铁律

**巅峰期看机会，低谷期别动。**

多数人在低谷期（被裁、被打压、干不下去）离职——最顺应人性，但恰恰最错误。
正确做法：在巅峰期（人人对你笑脸相迎、业绩最好时）往外看机会。不一定要跳，但必须去看。

## 三个支撑理由

### ① 口碑定格效应
"一家公司所有人对你的评价，都会定格在你离职时的那个状态。"
- 你走的时候是什么状态，你在前东家的口碑就永远是什么状态。
- 每次低谷离职 → 业内口碑持续下滑，且不可逆。

### ② side reference（侧面背调）必然发生
- 职业中后期，待过的公司大概率不超过10家，且极可能在同一个圈子里。
- 新东家打听你业内口碑的成本极低——"其实就是微信上发个消息的事"。
- 你控制不了别人怎么打听你，只能控制自己在口碑好时离场。

### ③ 心态决定谈判力
- **低谷期**：不配得感最强 → 严重干扰你做正确的谈判和重大决策（不敢报高价、不敢反价、轻易妥协）。
- **巅峰期**：思路清醒冷静甚至有点膨胀 → 能知道真实市场价 + 拥有最重磅筹码。
- "这两个状态，哪个能把钱谈得更高，就不用我多说了。"

## 决策对照

| | 低谷期离职（多数人） | 巅峰期看机会（布布糕建议） |
|---|---|---|
| 人性 | 顺应人性 | 反人性但正确 |
| 口碑 | 定格在低谷，持续下滑 | 定格在巅峰，加分 |
| side reference | 翻车风险高 | 加分 |
| 心态 | 不配得感→谈判吃亏 | 清醒自信→拿到真实价+筹码 |

## 实操建议

1. **巅峰期必须往外看几回**（不一定要跳）：校准真实市场价、积攒筹码。
2. **低谷期先稳住别动**：不配得感会让你做出错误的谈判和决策。
3. **意识到口碑是「定格」的**：离职时的状态 = 你在这家公司的永久标签。
4. **职业中后期圈子很小**：待过的公司不超过10家且多同圈，side reference 必然发生，别心存侥幸。

## 关于离职理由（negative reason）

布布糕提出「离职一定要有个 negative reason（负面理由）」——即离职需要一个正当的、令人信服的理由（而非"待得好好的突然要走"）。

巅峰期离职的矛盾点：巅峰期人人对你笑脸相迎，negative reason 从哪来？
- 解法：合理理由如"平台遇到天花板""想尝试更大scope/不同赛道""行业转型"，而非"混不下去了"。
- 关键：理由要真诚且指向"向前看"，不要指向"逃离现状"——否则又掉回低谷期心态。

## 与谈薪的衔接

模块A的终点就是模块C的起点：
- 巅峰期 = 你清楚自己价值 + 手握筹码 = 谈薪时自然拥有"确定性"和"稀缺感"。
- 这正是谈薪四阶段里"传递确定性、保留稀缺感"的物质基础。
