# 模块H · 简历制作与美化

> 提炼自《手把手教你做简历》《一些关于简历的基本法》。
> 核心立场（布布糕原话）：**改简历本身没什么大价值**——猎头公司实习生两三天就能掌握开简历技能，HR/猎头找人时根本不在意格式细节。简历之所以成"产业"，是社媒上无良HR贩卖焦虑的结果。

## 第一性原则：精简 > 篇幅

- 简历不是给自己看的（满满当当不留白是强迫症的舒适区），而是给**一天看几百份**的HR看的。
- 外企第一印象标签：不够 **simplified** = 直接扣分。"写自传一样的简历"会让HR头疼。
- 简历能不能造假？**化妆可以，换头不行。**

## 一、简历结构（自上而下）

| 板块 | 要点 | 避坑 |
|------|------|------|
| 个人信息 | 顶部，简洁 | — |
| 自我评价 | **概括总结工作经验**；硬技能生可写对某行业/职能的热情+为此做的准备 | 不要写软性性格（乐观开朗/爱旅游打球打麻将）——大陆就业市场 personality 无足轻重 |
| 学历背景 | 时间+学校+学历+专业，四要素即可 | 不写乱七八糟课程凑字数；**学历拿不出手就把学历放到工作经验后面** |
| 工作经验（重灾区） | 职责：5年经验以上 4–5 个 bullet；5年以内 3–4 个 | 不要写小作文 |
| 工作成就 | **必须数字化、具象化**，让对方有明确概念 | 模糊描述=无效信息 |
| 附加内容 | 学术论文、获奖、软件技能 | — |
| 兴趣爱好 | 不推荐写；年轻人想彰显个性可写，但**分清主次** | — |

## 二、哪些是"红线"（造假零容忍）

这三项一旦被查出，外企会上升到 **integrity（诚信）** 高度，在一个圈子里"真有可能混不下去"：

- **时间线**：gap 几个月别改成无缝衔接。三方背调（查犯罪记录+学历+时间线）会比对，篡改=诚信问题。
- **学历**：隐瞒低学历同样不可取。最多在**第一次电话沟通（敲门砖）**时模糊处理，但必须在这次沟通里讲清楚——越早亮出不利因素越好，否则最后竹篮打水一场空，"跟打官司不能瞒自己律师一个道理"。
- **薪资/诚信板**：薪资造假传开后，HR虽无封杀权，但圈子小，会"混不下去"。

## 三、哪些地方"可以改"（不算造假）

### 1. Title（最值得改）
你的内部 title 可能让你错失机会。例：你是"供应链经理"但上面已无供应链的人、汇报给 CFO/COO、前任对标外面的高级经理/副总监 → **对外 title 从 Manager 改成 Head / Lead**。
- Manager = 内部等级；Head = 你在大盘里承担的位置。**不算造假。**
- 怕背调 title 出问题？**拿 offer 前跟HR打个招呼**即可，不是大问题。

### 2. 项目经验（高难度，可操作）
- 面试官判断"你做没做过"靠 **probing（围绕一件事不断追问深挖）**：聊得下去=做过，卡壳=没做过。
- 只要你对项目的**关键节点、分工、合作**都了然于胸、经得起深问，即使只是团队成员，也可以写成自己负责——面试中的项目不做背调，能讲足够细对方就买单（"买单"=相信是你做的，不是越细越好）。
- **实用夸大**：带10个客户可吹15个；省80万可说100万——但**必须经得起追问**，不熟的内容宁愿别写。

## 四、设计师特别提醒
- 简历照别花里胡哨。
- **portfolio 和简历分开**：在作品集里穿插工作经验，HR看起来"真的很累"。

## 执行步骤
1. **先删后写**：把与目标岗位无关的内容全部删掉，确认精简。
2. **成就数字化**：每条工作成就补一个数字/百分比/金额。
3. **查红线**：时间线是否无缝造假？学历是否隐瞒？薪资是否虚报？
4. **可改项**：title 是否被低估（可升 Head/Lead）？项目是否经得起 probing？
5. **反向自检**：假设面试官对每条 bullet 连问3个为什么，哪条会卡壳？卡壳的就删或改写。
