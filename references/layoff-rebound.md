# 模块J · 裁员自救与快速找下家

> 提炼自《如果被裁员怎样最快找到下家》。
> 核心认知：裁员时你的**主要竞争对手不是市面上看机会的人，而是同一批被裁的同事**——时间线越往后拖，有限的职位越可能被同事抢走。所以争分夺秒。

## 一、裁员基础知识（先认清时间窗口）

- **裁员决策前期，参与决策的人一般不签 NDA** → 一定有小道消息，且散播极快。
- 听到裁员风声 → 衡量自己被裁概率：**高于 30% 就立刻行动**。
- **从风声出现到正式裁员，一般不超过 3 个月**（裁员讲究快狠准，有些公司一个月内裁完；外企 Global 自上而下可能拖到 2–3 个月，超过的极少）。
- 理想状态：听到风声后 **1–2 个月内**找到下家。

## 二、行动顺序（别一上来就海投）

### 第一步：简历更新不要拖
听到裁员消息**马上更新简历**。但更新完，**绝大部分人的下一步（招聘渠道海投）优先级是错的**。

### 第二步：先打竞品公司内推（最精准）
- **OpenChannel（猎聘/Boss/领英）致命问题：假职位太多。** 假职位不一定是造假，而是"长期挂着但根本不急招"的职位——招聘端一键刷新，看着像在更新，其实不动。
- 正确顺序：**列出你公司真正对标的竞品公司 → 把简历递给在那工作的前同事 → 拜托转给负责招聘的 TA**。
  - 没有前同事 = 说明它不是竞品公司。
  - 大厂可转给多个 TA（内部可能不流通，单线招聘的 TA 手里可能藏着你的职位）。
- **千万不要不好意思开口**——这条路线是最精准打击。别人无头苍蝇海投时，你可能已经跟 TA 通上电话了。
- TA 最喜欢竞品公司的人；够好的话，**没职位也愿意聊**；竞品内推难度一定更低；还能顺便校准你**真实的市场价**。

### 第三步：竞品塞满后，才去 OpenChannel 海投
顺序是：**竞品内推 → 再海投**，不是反过来。

## 三、面试 & 入职时机

- 面试时**可以直接告诉对方**"现公司有裁员风险我才想走"——2025年了，没人觉得被裁=能力不行。
- 拿到 offer 后，把入职时间定在**礼包日（裁员补偿发放日）之后**：
  - 通常你拿 offer 时（约一个半月后）内部裁员基本采完/时间已知。
  - 你的 notice 本身就要一个月，再推推不超过两个月，下家都能接受。
  - **大礼包 + 无缝入职 = 最优解**，HR 都能理解配合。

## 四、万一裁员是假消息（三个月没裁）
看你手头的 offer 够不够满意——满意就走，不满意就留下。

## 执行步骤
1. **算概率**：听到风声先判断自己被裁概率，>30% 立刻动。
2. **列竞品**：列出 3–5 家对标竞品公司 + 找出在每家工作的前同事。
3. **内推先行**：把简历递给前同事转 TA，别先海投。
4. **海投兜底**：竞品内推铺完后，再去 OpenChannel。
5. **卡礼包日**：拿 offer 后入职时间定在裁员补偿发放之后，拿钱+无缝入职。
