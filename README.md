## 核心心法

1. **离职时机**：在巅峰期看机会，不在低谷期离职。（反人性但正确）
2. **谈薪本质**：谈薪不是终面后两人对立博弈，而是贯穿整个面试、顺其自然的过程——前期越到位，后期越流畅。
3. **谈薪三大底层动作**：算清 Total Package + 初面定准范围 + 终轮给两个数字。
